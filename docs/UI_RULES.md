# UI Rules

## General

Mobile First.

Everything should feel like a native iOS app.

---

## Hero

Height:
320px to 360px

Contains:

- Wizard
- Clouds
- Sparkles
- Soft radial glow

---

## Cards

White surface.

Large radius.

Soft shadows.

---

## Bottom Navigation

Floating.

Height:
72px

Large pill shape.

White translucent background.

Backdrop blur.

Bottom spacing:
16px + safe area.

Only active tab displays text.

---

## Animations

Wizard:
- Floating
- Slight rotation
- Blinking

Clouds:
- Parallax

Buttons:
- Scale
- Soft spring

Cards:
- Scale
- Flip

---

## Performance

Use:

transform
opacity

Avoid:

top
left
width
height animations.
